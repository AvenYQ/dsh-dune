# dsh-dune

给 DeepSeek Harness 的暖色皮肤：米纸般的表面、克制的字号与字重、轻微回弹的侧栏动效，外加一套可自定义的工作区图标。

配色不是写死的——内置七套方案，也可以用一句话让 AI 生成一套新的。

从 0.2 开始，两套文字动效也内置进来了：**逐字浮现**（原 `dsh-reveal`）和**彗星光标**（原 `dsh-smooth-cursor`）。它们和配色一样放在「设置 → Dune」里，开关即时生效，不需要装额外插件。

## 0.5.1 更新

- 修「DSH 更新后侧栏入口只剩图标、文字不见，入口叠在一起」：DSH 新版给每个侧栏入口包了一层外框（入口按钮 + 原生「从侧边栏取消固定」按钮），入口文字也加了淡入动画。Dune 的「拖动排序 / 收进更多」原来是把入口按钮直接挪来挪去，于是按钮被挪出了外框、外框只剩高度为 0 的空壳，React 又不停把它们放回原位，两边来回拉锯，淡入动画每次都从透明重新开始，文字就一直看不见。
- 现在排序只改外框的 CSS `order`，收起只给外框打标记隐藏，不再移动任何 DOM；侧栏只在自身变化时才重新同步，对话流式输出不再触发。
- 被旧版弄乱的侧栏会自动修好：按钮按名字放回各自的外框，React 已经重新画过的旧按钮直接藏掉。拖动排序、拖到「更多」收起、设置里的显示/收起开关用法都不变。

## 0.5.0 更新

## 0.4.2 更新

- 修「窗口拖不动、只能顶着最上端一条缝拖」：彗星光标那张铺满窗口的透明画布挂在 `body` 上，宿主的 `body > :not(#root) { -webkit-app-region: no-drag }` 会把它判成禁止拖动，于是整窗的拖拽区被这一层减掉；画布即使 `pointer-events:none` 也挡不住。

## 使用

与 `dsh-quiet` 是两个独立皮肤，同一时间只启用一个。

**不要同时安装 `dsh-reveal` 或 `dsh-smooth-cursor`**：它们的功能已经内置在本插件里，重复安装会抢同一套渲染位和光标覆盖层。

## 外观设置

设置 → **Dune** 里有四块内容。

### 配色

- **当前方案**：显示正在用的配色和色板，可一键恢复默认。
- **预设方案**：原色、暖砂陶土、在路上、苔原、海盐、暮紫、琥珀，点一下立即生效，不用重启。
- **让 AI 设计**：写一句想要的气氛（例如「雨后的灰绿，配一点旧铜色」），复制指令发给对话里的 AI，它会调用 `dsh_dune_design_theme` 生成并存下来。

明暗跟随「通用」里的主题设置。强调色会派生气泡、发送按钮、链接、引用 chip、侧栏选中态、「深度求索中」那一行的颜色，所以换任何一套配色，界面各处都会一起变。

### 动效

- **逐字浮现**：新回复逐字从模糊过渡到清晰；关掉回到系统原生消息渲染。
- **彗星光标**：输入框光标平滑滑动、带渐隐拖尾。点进输入框立刻出现，不用先打字；同时灰色占位提示会收起。光标高度与打字时一致，停手约 0.4 秒后开始呼吸式明暗变化（1.4 秒一个周期，透明度 0.35~1），移动或输入时保持全亮。下面跟三个子项：
  - **拖尾**：开关渐隐尾迹。
  - **颜色**：默认「跟随主题」，取当前配色的强调色，换配色时自动同步；也可以从 8 个预设色里挑，或用取色器自定义。
  - **粗细**：细 / 中 / 粗。
- **侧栏动效**：侧栏收起与展开时的弹性滑入。
- **帆船轮次导航**：右侧轮次导航改用一条细航线，帆船会跟随当前阅读位置移动；点击与历史加载仍使用 DSH 原生日志。
- **推理等级滑轨**：打开模型菜单后直接拖动鲸鱼，在 Low / High / Max 之间切换，不再进入第二层。Low 为 DeepSeek 蓝色，High 为粉紫色；拉到 Max 会点亮并流动闪烁的像素星河，同时出现拍岸式星芒。

这两项可以分别关闭；关闭后分别回到原生轮次导航和原生二级推理菜单。

### 材质

- **玻璃质感**：输入框的半透明玻璃效果（背景模糊 + 内高光）。
- **背景纵深光**：会话区自上而下的轻微渐变。
- **隐藏滚动条**：藏掉系统滚动条。
- **紧凑圆角**：把界面圆角收紧到 6 / 10 / 14 / 20。

### 排版

- **Dune 排版**：正文 500 字重、24px 行高与紧凑段落间距。
- **自定义工作区图标**：用 Phosphor / Kubai 图标替换默认文件夹图标。

所有开关默认全开，观感就是 Dune 原本的样子；关掉哪一项就回到系统原生表现。

## 配色的一条规则

表面色（`bgBase` / `bgLayer1~3` / `bgOverlay`）只在画布上下浮动 2~3 个色阶，**不要用纯白**。

代码块、工具卡这类浮层如果铺 `#FFFFFF`，压在米色或中性画布上会差十几个色阶，看着像一块发光的白卡片，和周围不是同一种材质。需要「更亮」时提一个浅阶即可，不必冲到纯白。

## AI 直接调用

工具 `dsh_dune_design_theme` 接受一段 JSON：

```json
{"name":"暖砂陶土","colors":{"accent":{"light":"#A9603E","dark":"#D18C66"}}}
```

每个槽给 `light` 与 `dark` 两个十六进制颜色，未提供的槽沿用默认值；`reset=true` 恢复默认。

可用槽位：`bgBase`、`bgLayer1`、`bgLayer2`、`bgLayer3`、`bgOverlay`、`sidebar`、`textPrimary`、`textSecondary`、`textTertiary`、`textCaption`、`border1`、`border2`、`border3`、`border4`、`hover`、`accent`、`link`、`error`、`warning`、`success`、`idle`。

`link` 用来单独指定链接色（不给就跟随 `accent`）；`warning` 可以用来承载一个第三色，比如「在路上」里那条路牌的芥末黄。

## 工作区图标

把鼠标移到侧栏的工作区行上，点右侧的 **`…`**，菜单里在「重命名」和「删除工作区」之间多出一条 **「图标 ›」**。指向它，右侧展开第二层面板：上面一排颜色（含「跟随主题」），下面 51 个 Phosphor 图标（21 个常用 + 30 个有趣），底部「恢复默认」。

选中即保存，按工作区 ID 记录，重命名工作区不会丢。文件夹类图标在行展开时会切换成打开态。

也可以交给 AI：`dsh_dune_set_workspace_icon` 接受工作区名称、路径或 ID，配 `icon` 与 `color`，`reset=true` 清除。

## 已知取舍

- 内置的逐字浮现不声明 `conversation.chat.reasoning.body` / `conversation.chat.message.images` 两个子渲染位——chat 自己也声明了它们，重复声明会让 chat 的原生渲染位注册失败，那样关掉逐字浮现就回不到原生界面。代价是：展开的思考正文由本插件自己渲染 Markdown；消息里的图片按 DSH 的约定，在没有安装图库渲染插件时省略。
- 关闭逐字浮现后历史消息按原生渲染重绘，当前正在流式输出的那一条会闪一下。
